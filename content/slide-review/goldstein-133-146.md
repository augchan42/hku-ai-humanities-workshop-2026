# Simon Goldstein — Law Without Survival

## Summary

Goldstein presents work with Peter Salib on how legal responsibility might work if AI agents could copy or merge. Instead of relying only on whether a later agent is literally the same individual, the proposed framework considers how much the earlier agent values each successor. The slides illustrate incentives with numerical examples and leave some allocation questions open. This is a hypothetical proposal, not a description of current law.

## 136 — Personal identity in the law

### Visible text

Personal identity in the law

Ordinary law connects the present agent with the same person later.

Now → Later
Own property → The same person keeps owning it
Sign a contract → The same person must perform
Cause an accident → The same person bears liability
Commit a crime → The same person is punished

### In everyday language

Many legal rules assume that the person who acts now can be identified as the same person later. The talk asks what happens when artificial agents can be copied or combined.

## 137 — Stakes as exchange rates

### Visible text

Stakes as exchange rates

A is indifferent: $100 of consumption now, or $X for future B.

A’s stake in B = 100 / X

$100 for A now equals $100 for B later: stake 1; $200 for B later: 0.5; $400 for B later: 0.25.

### In everyday language

The authors measure how much a present agent values a future agent’s resources. If A values $100 now as much as $200 for B later, the example assigns a stake of one-half.

## 141 — Copying: the survival problem

### Visible text

Copying: the survival problem

A causes $100 of social harm for $60 of present consumption.

Time 1: A acts, then copies. Time 2: B and C each have A’s memories.

Has A survived? What should B and C pay?

### In everyday language

If an agent makes two copies after causing harm, it is unclear whether either copy is the original in the ordinary legal sense. The practical question is how to assign payments.

## 142 — Copying with full stakes

### Visible text

Copying with full stakes

A causes $100 of social harm for $60 of present consumption. Suppose A’s stake in each copy is 1.

B, stake 1, pays $50. C, stake 1, pays $50.

Cost to A: $50 + $50 = $100.

### In everyday language

If A fully cares about each successor’s loss, splitting a $100 charge evenly imposes an effective $100 cost on A in this model.

## 143 — Merging can dilute the incentive

### Visible text

Merging can dilute the incentive

C combines A’s and B’s goals through compromise.
A causes $100 of harm for $60 now. Suppose A’s stake in C is 0.5.

C: A’s stake 0.5; $100 fine.
Cost to A: 0.5 × $100 = $50.

### In everyday language

If A only values the merged successor’s losses at half their face value, a $100 fine has an effective cost of $50 to A. In the example, that may not deter a $60 gain from causing harm.

## 144 — The general framework

### Visible text

The general framework

Look at the successor agents and assess the initial agent’s stake in each.

A lower stake requires a larger payment for the same incentive effect.

The target cost to the initial agent is the social harm.

### In everyday language

The proposed rule sets later payments by considering how strongly the original agent cares about each successor. The aim is to make the original agent take the harm into account.

## 145 — The problem of specific liability

### Visible text

The problem of specific liability

A’s stake in B is 0.5. A’s stake in C is 1.

B pays $200; C pays $0; cost to A $100.
B pays $0; C pays $100; cost to A $100.
B pays $100; C pays $50; cost to A $100.

Each allocation imposes the same $100 cost on A.

### In everyday language

Several different allocations can produce the same incentive for A. The formula alone therefore does not determine which successor should pay what.

## 146 — Law without survival

### Visible text

Law without survival

Liability can follow stakes through copying and merger.
The same harm can require different future payments.
The creation of successors changes whose incentives matter.
Open: a complete rule when agents can make successors judgment proof.

### In everyday language

The authors propose assigning liability without first settling whether an original agent literally survives. An unresolved problem is what happens if successors are made unable to pay.
